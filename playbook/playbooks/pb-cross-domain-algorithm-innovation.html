跨域算法创新手册

从酒店运筹学、控制论、博弈论迁移顶级算法，构建竞品无法复制的AI能力护城河

算法迁移 · 创新范式 · 竞争壁垒
母婴跨境电商的算法同质化严重——大家都在用需求预测、价格弹性、A/B测试。真正的竞争壁垒来自「别处心裁的算法迁移」：把酒店收益管理迁移到SKU容量定价，把火箭制导的Kalman Filter迁移到库存信号滤波，把博弈论迁移到竞争定价，把行为经济学迁移到促销设计。这些算法在本行业几乎无人使用，但在各自的原生领域已被证明有效。本手册是一本「算法创新地图」，指引从传统电商算法到跨域顶刊迁移的升级路径。

Step 1 — Revenue Management迁移：从酒店定价到SKU容量管控

你知道FBA库存和酒店房间有什么共同点吗？都是有限容量+时间窗口+不能存货。酒店用了30年的EMSR模型可以直接迁移。

EMSR-b Bid-Price Inventory Control — 酒店边际座位收益模型迁移到FBA库存动态定价
16-30万元⭐⭐⭐☆☆

→ EMSR-b模型：计算每个库存单位的边际价值，需求旺时自动提价，淡时降价清仓

Perishable Inventory Markdown Optimization — 超市易腐品定价运筹学迁移到母婴临期/过季商品
1000万⭐⭐⭐☆☆

→ 易腐品动态规划降价：婴儿食品临期/季节品过季，DP算法找到最优降价时间表

Revenue Per Available SKU（REVPAS）— 以可售库存单位衡量定价效率
2.4 万⭐⭐⭐☆☆

→ REVPAS指标：RevPAR思维评估每个可售库存单位的综合收益，找到定价效率最低的SKU

所需数据：需要：历史销量-价格数据、库存水位时序数据、竞品价格数据
输出结果：SKU容量价值矩阵 + 动态定价触发规则 + REVPAS排行榜

Step 2 — Kalman Filter迁移：从火箭制导到库存信号滤波

需求预测的最大敌人是噪声：促销噪声、季节噪声、竞品促销干扰。Kalman Filter是1960年代解决这个问题的最优答案。

Kalman Filter 需求状态追踪 — 在噪声销售数据中实时追踪真实需求
1500万⭐⭐☆☆☆

→ 实时追踪需求真实状态：区分信号和噪声，比移动平均精准3-5倍

PID 安全库存控制器 — 将工业自动控制迁移到动态安全库存调整
2000万⭐⭐☆☆☆

→ PID控制器：比例-积分-微分三项驱动安全库存自适应调整，不再用固定安全系数

自适应补货点 Kalman 版 — 让 ROP 随市场需求动态漂移
2-5万⭐⭐☆☆☆

→ 自适应补货点：ROP随Kalman估计的需求均值和方差实时漂移，比传统ROP误差降低40%

所需数据：需要：日级销量时序数据（≥90天）、补货到货记录、供应商lead time数据
输出结果：需求真实状态估计曲线 + 自适应ROP + 安全库存调整建议

Step 3 — Choice Modeling迁移：从心理学到购买决策

传统推荐预测「用户会点击什么」，离散选择模型预测「用户为什么选这个不选那个」。一个是相关性，一个是因果性。

MNL购买选择模型 — 用效用函数建模「为什么选A不选B」
3000万元⭐⭐⭐☆☆

→ MNL模型：估计价格/评分/品牌/配送时间各属性的边际效用，输出竞品胜出概率

支付意愿估计 — 从MNL参数推导用户真实WTP分布
2000万元⭐⭐⭐☆☆

→ WTP估计：从选择数据中估计各用户段的最高支付意愿，找到差异化定价的理论上限

联合分析产品设计 — 用CBC+层次贝叶斯量化消费者属性偏好
80-150 万元⭐⭐⭐⭐☆

→ 联合分析：新品开发阶段，用CBC实验量化消费者对BPA-free/有机/价格各属性的权重

所需数据：需要：搜索页曝光+点击+购买数据、用户属性数据（可选）
输出结果：属性效用权重表 + WTP分布 + 产品设计优先级建议
向 AI 咨询此步骤 ◈ 调用 Agent 执行

4.2 万⭐⭐☆☆☆

→ 共享编码器迁移：同类SKU共享需求模式，新SKU仅需2周数据即可获得可靠预测

旺季模式迁移学习 — 新品首次黑五从老品学习放大系数
6.8 万⭐⭐☆☆☆

→ 旺季模式迁移：新品首次面对黑五，从同类老品学习旺季放大系数

跨市场需求迁移学习 — 用成熟市场数据加速新市场冷启动
3.6 万⭐⭐⭐☆☆

所需数据：需要：同类老SKU历史数据（≥6个月）、新SKU近期销量数据
