## 1 为什么移出

| 理由 | 说明 |
|---|---|
| 判据只能有一处 | 契约校验器 `check_contracts.py` 用 `CONTRACTS_DIR.rglob("CTR-*.md")` 扫全目录。留在原地的 v1 底本会与 S1 新写的 v2 **同 contract_id 重复入账**，J10（A+B 计数 = 73+66，覆盖且不重复）当场判红 |
| v1 已冻结 | 撰写规范 §5 原话：「S1 之后统一走 v2，两个目录合并」。v1 无 `template_version` 字段 ⇒ 校验器按 v1 口径免检并**如实报出免检份数**。S1 起不再产生 v1 |
| 不能删 | 这 7 份是 F6（负结果）与 F7（五臂确定性诊断）的**处理臂底本**。删掉它们，两份报告的结论就只剩叙述、没有可复核的输入 |

**移出而不是删除，也不是留原地加豁免。** 加一条「跳过某目录」的豁免正是本仓库吃过四次亏的东西
（新增一个不阻塞的结局 = 新后门）；移出到扫描根之外，则豁免逻辑根本不需要存在。
