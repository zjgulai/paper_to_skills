## 3. #76 去归属标记**自己被读成了归属**（本轮最该留下的那条）

改完后 L4e 从 exit 0 变成 **exit 3 + 1 条假红**。追下去发现：

```
摘录（改后）：本项目综述 §F.3 记 AGT-013 的判定（**二手来源，不是材料原文**）：「缺陷收敛…」
仪器取到的 `材料` ← ↑ 就是标记里的那个
run = '原文**）'  →  命中 RUN_ATTRIB  →  判为「材料原文」→ 引文回查失败 → 红
```

- **那句引文是真的**：它逐字来自 `_survey_org_model.md:694`。
- **一句明说「不是材料原文」的话，被仪器读成了「材料原文」** —— 这不是判据不够严，是**判据把否定读成了肯定**。
- 另外 3 处因 `run` 形态没进白名单，直接变 `unclassified` ⇒ **exit 3**（漏测 ≠ 通过，仪器这一层是对的）。
- ⚠️ **为什么以前没炸**：旧措辞下这些引号落在 `len(seg) - (pos+2) > 20` 的**距离窗之外**，
  被**静默跳过**。⇒ **不是判据对，是判据没看见。** 改标只是把标记挪近了，仪器才开始看见它们。

**修法**（`check_material_citations.py`）：新增 `DEATTRIB_NEG` + `mask_deattrib()`，
把**否定/缺失形态**（`(不是|非|并非|不算)材料(原文|章节号|…)`、`材料(未给|没有|未命名|…)`）
换成**等长**占位符（等长 = 不破坏引号偏移）再走常规路径。该行若再无别的 `材料`，
这条引号**本就不该算材料引文**（与既有 `non_attrib` 同一语义）。

**反向控制**（豁免条款必须比拦截条款测得更严）· `--selftest` **11 → 15**：

- ⑫ `（不是材料原文）：「X」` ⇒ 不计为引文，也不得 `unclassified`
- ⑬ **`（材料原文）：「X」` 且 X 不在材料里 ⇒ 必须照旧判红**（证明遮罩只对否定形态生效）
- ⑭ 正常归属路径不得被关掉
- ⑮ 遮罩必须**等长**

**读数**：语料上回到 **88 条引文 / 39 词 · exit 0**，与改标前**逐项相同**
（中间态是 89/40 + 1 红 + exit 3）⇒ **是语料被读对了，不是判据被放宽了。**

## 5. #78 「交付不是接线」第四次 —— 根因是**豁免的颗粒度太粗**

`check_material_residue.py`（#67 交付）从未进验收面。与 **#23 / #69 / #71 同族**，
但这一次根因不同：**它不是忘了接**。#67 的工单明写「家族一未定标 ⇒ 不得进门禁」，
理由是「把一个未定标的仪器接进门禁＝制造噪声」—— **这条判断是对的**。
错的是它的**颗粒度**：仪器有两族判据，只有一族未定标，而豁免加在**整台仪器**上
⇒ 那一族**精确的**（已逐号对材料核实的）判据跟着一起隐形了。

> **豁免的颗粒度就是判据的颗粒度。**
> 本仓库已因颗粒度翻面过三次（列 vs 行 vs 块 · `red_findings` vs 判红卡数 · 本条的仪器 vs 家族）。

**修法**：残留器新增 `--family {all,terms,sections}`，**判定与退出码按族分离**，
未判的那一族**在输出里明写「只扫不判 —— 未判定 ≠ 干净」**。
