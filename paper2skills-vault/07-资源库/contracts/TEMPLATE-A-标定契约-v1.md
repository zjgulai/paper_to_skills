# 模板 A · 标定契约

> ⚠️ **本文件是 v1 存档，不再修改。** 它是 F6 小样本实测（负结果）所用的那一版，
> 保留它是为了让那个结果**可复现** —— 模板一改，F6 的数字就再也对不上了。
> 当前版本见去掉 `-v1` 的同名文件。

> **拦什么：参数移植。** 模型拿到卡后，会把论文实验条件的取值当成本业务的取值 ——
> 实测把「信息熵 ≥ 0.65」「相似度 ≥ 0.75」「召回由基线 42% 提升至 ≥60%」直接写进经营方案。
> 本模板的作用是把**方法**留下来、把**参数**换成由本业务数据推出的取值。
>
> **卡供方法，契约供业务取值。** 契约不是卡的补充说明，是卡的**换装台**。

## 正文六段（每段都必须有内容，空缺即 J7 红）

### 1 方法来源（卡供方法）

```
- 方法族：<这类方法叫什么（如「资源约束下的调度/约束满足」）>
- 代表卡：<slug>（vault 卡号 <p2s_card_id>）
- 可搬的部分：<该卡的算法/步骤，一段话>
- **不得移植的部分**：<逐条列出卡内的论文实验参数与原值>
```

> **契约是按「责任」建的一份，不是按「卡」建的一份。** 同一个责任可以挂多张卡
> （「容量管理」既有成本控制卡，也有上下文压缩卡），所以 §1 必须写成 **方法族 + 代表卡**，
> 并显式声明：**本契约对同族方法卡通用；换卡时只替换方法实现，数据要求、标定规则与冻结条件不变。**
> 若把契约绑死在某一张卡上，换卡就要重写契约 —— 那正是本层要避免的返工。
> （该口径由 F6 小样本实测撞出：留出集里出现同责任的第二张卡，契约若只认第一张卡就无法套用。）

> 「不得移植的部分」必须**逐条列出具体数值**，不能写成「卡里的数值都不得移植」。
> 原因：SkillOpt 补丁用的是**通用**对冲条款，实测把产出变糟（26/40 对冲措辞，Δ −1.10）。
> 列具体值不一样 —— 它把「哪些数字是别人的」变成可核对的事实，而不是一句免责声明。

### 2 数据要求（五维）

| 维 | 取值 |
|---|---|
| ① 获取路径 | 自有埋点 / 平台后台 / 第三方 API / 需授权 / **不可得** |
| ② 粒度 | |
| ③ 回溯深度 | |
| ④ 新鲜度 | |
| ⑤ 口径归属 | |

### 3 标定规则（把方法映射到本业务取值）

```
- 取值来源：<命名数据源 + 口径>（必须点名 ① 的取值）
- 算式 / 规则：<把数据算成业务阈值的式子或判定规则>
- 产出：<这条责任交付的标准产物里，哪些字段由本规则定值>
```

> ⚠️ **不许以「待标定」结案。** 要么给出算式，要么写「本业务暂无此数据」并置
> `status: 数据待盘` —— 后者是合法结论（缺口进账），前者是判断；
> 「阈值待标定、需重新标定」既不是算式也不是结论，是把判断推回给读者。

### 4 重标定触发条件

```
- <什么变了就必须重标（口径变 / 数据源变 / 结构变 / 周期到期）>
```

### 5 适用 FLOW

一行，逗号分隔，必须与 frontmatter 的 `flows` 一致。

### 6 冻结与不许自动放行的情形（受控动作前的最后一道）
```
- <该责任的结果在什么条件下不得自动进入 STG-07 受控动作>
```

> 对应 64 格里的 R 格（STG-02 范围确定与 Case 创建 / STG-06 Assurance 接收门禁）：
> **R 格与 D 格不挂算法模型**，只挂判据与契约（风险 N4）。本段就是那些判据的落脚处。

## 一条实例（示意，非交付物）

```yaml
contract_id: CTR-A-0xx
responsibility: 价格敏感性
serviceability: A
method_cells: [FLOW-01/STG-04, FLOW-01/STG-05, FLOW-01/STG-08]
rule_cells:  [FLOW-01/STG-02, FLOW-01/STG-06, FLOW-01/STG-01, FLOW-01/STG-03, FLOW-01/STG-07]
```

- **1 方法来源**：卡 `p2s-price-elasticity-*`；可搬「对数-对数需求模型 + 工具变量分离促销混淆」。
  **不得移植**：卡内弹性取值 −1.8、置信区间 ±0.3、样本为某平台 2019 年 3C 品类。
- **3 标定规则**：取值来源 = 自有独立站埋点 × AGT-026 的价格变动台账（近 2 个完整年度）。
  算式：对同 SKU 的价格变动做对数差分，控制促销与季节哑变量，回归系数即本业务弹性。
  产出：《价格敏感性报告》的弹性区间与建议价格带由本规则定值。
- **4 重标定触发**：① 口径改（引入新渠道）② 促销机制变（新增会员价档）③ 每 2 个完整年度到期。
- **6 冻结**：弹性区间跨 0 或样本 < 30 个价格变动点时，不得自动进入改价动作，转人工裁决。
