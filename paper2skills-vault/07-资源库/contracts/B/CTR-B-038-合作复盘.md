# 合作复盘 · 供给契约

> **本契约的两部分，用法不同。** §1 算法可达部分 / §2 不可达部分 / §3 必须的外部证据与责任岗位 / §5 数据要求 / §6 适用 FLOW 是**作业口径** ——
> 据此产出方案：可达段给算式与取值，不可达段给替代路径。§4 是**放行判据** —— 它规定的是「什么条件下不许自动走」，
> **不得整句抄成交付物的内容**。
>
> **本责任的判定理由**（`_survey_org_model.md` §F.3）：效果归因可用增量测量与全成本核算建模，但**合同条款、关系维护与续约属商务判断**。
> 这句话就是本契约可达段与不可达段的分界线：**能算的是「这一次合作花了多少钱、带来多少增量、内容还能跑多久」**；
> **不能算的是「条款怎么解释、对方是否真的履约、要不要继续合作」** —— 后者只能由实物回执、法定签署与治理判断补上（§2、§3）。
> 归属岗位 `AGT-033 达人与联盟合作`；本责任同时挂在 FLOW-02（新品需求到商业验证）与 FLOW-04（市场进入与合规上架）两条 FLOW 上 ——
> 前者的达人合作服务于**新品受控外部验证**，后者的达人合作服务于**新市场本地化启动**，两者的可达段算式相同、证据链不同（见 §3）。
>
> **本契约覆盖的格**：方法格 FLOW-02/STG-04、FLOW-02/STG-05、FLOW-02/STG-08 与 FLOW-04/STG-04、FLOW-04/STG-05、FLOW-04/STG-08 —— §1 的算式落在这些格；
> 规则格 FLOW-02/STG-01（新品机会信号）、FLOW-02/STG-02（新品验证Case Charter）、FLOW-02/STG-03（FLOW-02 Context Manifest）、FLOW-02/STG-06（FLOW-02 Assurance Decision）、FLOW-02/STG-07（验证尝试或无动作记录），
> 与 FLOW-04/STG-01（市场进入信号）、FLOW-04/STG-02（市场进入Case Charter）、FLOW-04/STG-03（FLOW-04 Context Manifest）、FLOW-04/STG-06（FLOW-04 Assurance Decision）、FLOW-04/STG-07（上架尝试或无动作记录）
> **只放判据与门禁条件**，不接判别式与预测式（§4 的落脚处）。
>
> **取值来源纪律（全文适用）**：本契约出现的每一个阈值、比例与时限，来源只有三种 ——
> （a）业务处境或材料已给出的数（出海历史 **2 个完整年度**＝决策 Q11；增量测量主体＝**自有独立站为主**、独立站 holdback **没有、可以建但需先建**＝决策 Q9 / Q10；经营节奏「月度经营复盘」＝**1** 个自然月、「季度经营策略」＝**1** 个自然季度）；
> （b）业务侧默认（经营者自述或行业惯例，逐条写明替换条件）；
> （c）§1 算式的输出（由命名的数据系统直出）。**候选卡的论文参数与卡面 ROI 不构成第四种来源。**

## 1 算法可达部分

- **候选卡状态（先读这一条再用本段）**：本责任 3 张代表卡**全部是 legacy 预览版**（八段式）——卡页第 ④、⑤ 两段是占位串，第 ⑧ 段三张卡所记的 arXiv 号在 arXiv 上都是另一主题的论文（其中一张的号还被 **3** 张卡共用）。
  ⇒ **论文实验参数未随卡进入本包**，本段的可达写法由**本业务算式**定值，卡只供方法骨架；卡面可见数字逐条列在本段末尾，**任一条不得移植**。
- **可达段一（单次合作的全成本与增量回报 —— 本契约的取值出口）**：先按 `AGT-045` 的口径把一次合作的成本项凑齐，再算增量回报。
- 可达段一算式：`单次合作全成本 = 合作费 + 寄样成本 + 内容制作或授权费 + 平台佣金与支付费 + 履约与退货成本`；
  `增量GMV = 增量转化率 × 曝光人群规模 × 客单价`（倾向得分匹配后的可比样本）或 `增量GMV = 实测GMV − 对照期同窗基线GMV`（无匹配样本时的退化式）；
  `iROAS = 增量GMV ÷ 单次合作全成本`。源字段：〈达人合作台账〉（**尚未建账**，见 §5 ① 的顶替与替换条件）的合作费与结算单、〈平台后台〉达人/联盟后台与平台归因报表、《独立站埋点》的专属链接与优惠码归因、〈财务系统对账表〉的退货与支付费。
- 取值：**全成本口径 ＝ 上列 5 类成本项**（**业务侧默认**：经营者自述「达人合作的钱不只坑位费，寄样和退货也要算进去」）；**显著性判据 ＝ 增量转化率差的 95% 置信区间不含 0**（材料未另定显著性口径，沿用方法侧统计约定）；**分层档位 ＝ 按 iROAS 降序取前 30% 为「加投档」、后 30% 为「停投档」、其余为「维持档」**（**业务侧默认**：经营者自述「三分法好排期」）。
  **替换条件**：本店积累满 **2 个完整年度**的达人合作后，分层档位**替换**为按本店 iROAS 实测分布的 **P70 / P30** 分位；**决策 Q10** 的独立站 holdback 建成后，增量口径**替换**为 holdback 对照、`iROAS` 随之替换为随机对照下的估计；替换前所有增量结论必须标注「非随机对照」，且不得作为对外承诺或续约依据。
- **可达段二（归因口径对账：平台归因 GMV 与本司增量 GMV 的差）**：逐达人逐次合作算归因折扣率，作为与平台侧沟通和内部口径统一的依据。
- 可达段二算式：`归因折扣率 = 增量GMV ÷ 平台归因GMV`（同窗、同对象、同口径版本；分母取 `AGT-045` 口径下的平台归因 GMV）。
- 取值：**归因折扣率 ∈ [0, 1]**（> 1 表示平台低估，须先查口径版本再采信）。本业务**尚未算出本店实测折扣率** —— **先按**同一达人在〈独立站埋点〉与〈平台后台〉两侧同窗 GMV 的比值**顶替**为初始折扣率并逐条标「双源比值口径、非增量口径」；〈达人合作台账〉与〈财务系统对账表〉跑满 **2 个完整年度**后**替换**为实测折扣率；替换前该折扣率只用于**发现口径异常**，不得用于削减平台的归因值，也不得写进与达人的结算争议材料。
- **可达段三（内容生命周期与排期，避免自相蚕食）**：按发布后逐日 GMV 序列算累计占比，得 `T80` 与内容类型的实测衰减。
- 可达段三算式：`T80 = 使累计 GMV 达到该条内容总 GMV 的 80% 所需的天数`（对每条内容算，再按内容类型取本店分位）；排期规则：同类型内容在同一渠道的上新间隔 ≥ 该类型 `T80` 的 **P50**。
- 取值：**观测窗 ＝ 发布后 14 个自然日**（**业务侧默认**：经营者自述「两周之后基本没量了」；与该窗同阶，保证 `T80` 落在窗内可测）；**迭代间隔 ＝ 同类型内容 `T80` 的 P50**（由本店数据直出，**不采用卡面的 0.25 / 0.10 / 0.05 / 0.02 衰减速率与 4 / 7 / 14 / 35 天半衰期**）。
  **替换条件**：本店按内容类型各积累 ≥ 30 条内容后，观测窗**替换**为按该类型 `T80` 的 **P95** 加 **7** 个自然日；替换前 `T80` 只用于排期，不用于判断内容「失败」。
- **可达段四（达人分级与复盘记录回写）**：按 iROAS、匹配质量与合作全成本三键排序，输出分级清单回写关闭记录。
- 可达段四算式：排序键 ＝ （iROAS desc，`匹配率` desc，全成本 asc）；`匹配率 = 成功匹配到可比对照的曝光用户数 ÷ 参与匹配的曝光用户数`；`本期总增量回报 = Σ 各次合作增量GMV ÷ Σ 各次合作全成本`。
- 取值：**匹配率下限不设固定百分比，按「估计精度」反解** —— `匹配率下限 = 使增量转化率差的 95% 区间半宽 ≤ 该次合作增量GMV × 20% 的最小可比样本占比`（逐次合作由本店样本量与客单价直出，可比样本越少则下限越高）；**不采用卡面的 60% / 40% / 0.1 三个固定门槛**（见卡面数字清单第 9 条）。**分级输出为「加投 / 维持 / 停投」三档清单 + 逐条证据栏**，进入 FLOW-02/STG-04 的〈机会与可行性诊断〉、FLOW-04/STG-04 的〈市场进入诊断〉，并回写 FLOW-02/STG-08 的〈新品验证关闭记录〉与 FLOW-04/STG-08 的〈市场进入关闭记录〉。
  **替换条件**：本店跑满 **2 个完整年度**的达人合作后，精度约束**替换**为按单达人结论稳定性反解的区间半宽（同法反解、约束更严）；替换前匹配率不达反解下限的达人不进「停投档」，只进「证据不足」栏并留人工复核。
- **本段的能力边界**：只做四件事 —— 全成本核算、增量回报与折扣率、内容 `T80` 与排期、三档分级与回写；**不产出条款解释、不产出履约事实的认定、不产出续约与追偿的裁决**（见 §2 各条）。

## 2 不可达部分

- 不可达 ①（需**法定或治理签署**）—— 合同条款的解释与违约认定：保底量怎么算、独家期从哪天起、内容授权范围与期限、二次投流与二次剪辑是否在授权内 —— 这些是条款解释，不是数据问题。
  → 替代路径：由 AGT-043 法务与知识产权在 FLOW-02/STG-05 或 FLOW-04/STG-05 方案定稿前出具条款解读与边界结论；意见未到时，只把合同原文摘录与双方往来确认件摆出来当事实材料，明写「违约与否未判」；据此不得发起扣款、追偿或终止合作，这些只能进 Action Intent 并交人工签署，本格不自行认定哪一方违约。意见到位后按结论重判该次合作的分级与结算处理。
- 不可达 ②（需**实物或回执**）—— 达人的真实履约事实：是否按约定时间与形态发布、是否挂链、流量与互动是否真实（有无刷量）—— 本司只能读到达人愿意给的截图，读不到平台侧原始事实。
  → 替代路径：由 `AGT-033` 达人与联盟合作在 FLOW-02/STG-08 或 FLOW-04/STG-08 关闭前逐次回收发布回执与平台后台导出件、由 `AGT-031` 视觉视频与素材生产提供素材版本与发布时间戳；拿不到时先用达人自报截图顶替并标「自报未核」；后果是该次合作不进本期分级结论与结算争议材料，只能留观察项。
- 不可达 ③（需**实物或回执**，且方法前置未建）—— 干净的增量对照：**本业务独立站 holdback 没有、可以建但需先建**（决策 Q10）。在 holdback 建成前，任何「达人到底带来多少增量」都只是匹配推断，不是实测对照。

- 不可达 ④（需**外部事实**，且受**合规**约束）—— 跨平台身份打通：达人平台侧的用户与〈独立站埋点〉的订单之间没有可用的标识贯穿，用户级数据也不得导出至第三方。

- 不可达 ⑤（需**法定或治理签署**）—— 关系与商务判断：是否续约、报价谈到多少、是否长期绑定或独家 —— 属商务与治理判断，涉及资金占用与经营目标，不是可复算量。
  → 替代路径：由 `AGT-033` 达人与联盟合作主岗会同 `AGT-041` 经营财务与资金（资金与预算约束）与 `AGT-001` 经营目标与资源统筹（目标与资源位）在 STG-05 定稿前给出续约与报价建议；拿不到时只出「建议清单 ＋ 选择理由」，不给结论；后果是不得自动发出续约、加价或终止合作的意图，续约类动作只能进 Action Intent 由人工批准。
- 不可达 ⑥（需**外部事实**）—— 平台侧效果数据的口径与可读范围：平台归因窗口、归因规则与展示口径由平台单方定义且会随版本变化，本司只能记录版本号，不能改口径。
  → 替代路径：由 `AGT-046` 数据工程与质量在 FLOW-02/STG-03 或 FLOW-04/STG-03 装配上下文时给出该源的口径版本与可读范围；拿不到时先按当期导出件自带的口径说明逐次记录并标「口径随平台版本变化」；后果是跨期比较必须先按同一口径版本分组，否则该比较不得写进产物。

## 4 该格何时必须冻结

- 全成本不全（缺寄样、内容制作或授权、平台佣金与支付费、履约与退货任一项）而已算出 `iROAS` ⇒ 该排序不得用于档位划分，只能出「成本不全」标注并留人工复核。
- 增量结论的**非随机对照**状态未标注，或被表述为「实测增量」⇒ 该条不得进入 FLOW-02/STG-05 或 FLOW-04/STG-05 的结论栏，须回 STG-04 重算口径。
- 可比样本占比低于 §1 可达段四反解出的匹配率下限（即区间半宽 > 该次合作增量 GMV 的 **20%**）而仍给出单达人「停投」结论 ⇒ 该条不得放行，只能进「证据不足」栏。
- 合同条款解读未取得而拟动作涉及扣款、追偿、终止合作或内容下架 ⇒ 冻结至意见到位，改走人工裁决。
- 发布回执缺失而拟依据「未按约定发布」扣减或拒付 ⇒ 该动作不得自动执行，须由 `AGT-033` 主岗会同 `AGT-043` 人工认定。
- 用户级匹配数据的使用范围未经 `AGT-050`／`AGT-044` 确认 ⇒ 单达人归因结论立即冻结，只保留聚合口径。
- 跨平台间接归因结论被用作裁撤单个达人的**唯一**依据 ⇒ 该裁决不得放行，须补第二条证据（自有独立站归因或发布回执）。
- 平台归因口径版本在不同期次之间不一致（跨版本直接比较）⇒ 该比较结论不得进入产物，须按同一版本分组重算。
- 引用 §1 清单中任一条卡面案例数字或其实现默认值作为本业务取值（含 **4.2→1.8**、**44%**、**3.5**、**1.9→2.6**、**$4,500 / $7,200 / $18,000**、**2.1x→4.3x**、**>5x / 1.1x**、**0.25 / 0.10 / 0.05 / 0.02**、**0.7 / 0.35**、**21x** 等）⇒ 该方案不得放行。
- 同一达人或同一内容在当周内已有一次未回填的合作或投流动作 ⇒ 不得对同一对象发起新动作；已成功动作不得随整单重跑。
- 自 FLOW-02/STG-05 或 FLOW-04/STG-05 产物提交起，至该 Case Charter 已写明的观察窗截止日仍未取得 §3 中任一「STG-08 关闭前」类证据 ⇒ 判 HOLD 并转人工，不得默认放行。
- 合作复盘命中 FLOW-07 的重大事件口径（内容违规下架、达人舆情、平台处罚）⇒ 移交紧急保护通道（Emergency Guard），本格不得自行处置。
- 本条在 FLOW-02/STG-01、FLOW-02/STG-02、FLOW-02/STG-03、FLOW-02/STG-06、FLOW-02/STG-07 与 FLOW-04/STG-01、FLOW-04/STG-02、FLOW-04/STG-03、FLOW-04/STG-06、FLOW-04/STG-07 上落地的只是上列判据与门禁条件，不引入判别式与预测式。
