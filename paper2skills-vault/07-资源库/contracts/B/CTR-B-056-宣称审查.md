# 宣称审查 · 供给契约

> **本契约的两部分，用法不同。** §1 / §2 / §3 / §5 / §6 是**作业口径** —— 据此产出方案：可达段给算式与取值，
> 不可达段给替代路径。§4 是**放行判据** —— 它规定的是「什么条件下不许自动走」，**不得整句抄成交付物的内容**。
>
> 本责任的判定理由（`_survey_org_model.md` §F.3）：**宣称合规可用规则+分类器预筛，但判定含法律风险须人签署。**
> 这句话就是本契约可达段与不可达段的分界线：**命中、证据齐备性与标注缺失可以机检；是不是违法、能不能放行须人签。**
>
> 本责任由 `AGT-044` 安界·产品合规与隐私承担，交付物是「合规矩阵与证据缺口」，衡量口径是「覆盖完整性与违规阻断」，
> 在 FLOW-02（新品需求到商业验证）、FLOW-04（市场进入与合规上架）、FLOW-05（服务留存与复购）、
> FLOW-06（业务需求到数据产品与工具）、FLOW-07（重大质量与账号事件）五跳上出现。
> §1 的算式落在五条 FLOW 各自的 STG-04 证据收集与诊断、STG-05 方案与标准产物、STG-08 结果核验与关闭，
> 共 **15** 个方法接入格；§2 与 §4 的判据落在同五条 FLOW 的 STG-01 信号接收、STG-02 范围确定与 Case 创建、
> STG-03 上下文装配、STG-06 Assurance 接收门禁、STG-07 受控动作 —— **这五格只放判据与门禁条件**。
>
> **取值来源纪律（全文适用）**：本契约出现的每一个门槛、比例与时限，来源只有三种 ——
> （a）业务处境或材料已给出的数（出海历史 **2 个完整年度**＝决策 Q11；经营节奏「月度经营复盘」＝**1** 个自然月；渠道构成 Amazon **65%** / 独立站 **15%**，其余 **20%** 未定名＝开放事实 O1）；
> （b）业务侧默认（经营者自述、平台规则或行业惯例，逐条附替换条件）；
> （c）§1 的算式由命名的数据系统直出。
> **三张候选卡卡面的案例数字与实验参数不构成第四种来源**（逐条清单见 §1 末）。
>
> **方法族与本契约的关系**：本契约按「责任」建、不按「卡」建。三张代表卡
> （`p2s-aigc-content-compliance-review` 的假宣称扫描与 AIGC 标注检测、`p2s-multi-market-ad-copy-compliance`
> 的多市场声明类型矩阵与所需证据清单、`p2s-search-compliance-guard` 的双轨违禁词预扫与召回优先口径）
> 只提供方法族骨架；§1 三条算式的每一个输入都来自本司命名系统与已取回的政策原文，卡面数字一条都不进本业务口径。

## 1 算法可达部分

- **宣称命中与分类（逐句逐词的命中清单，落五条 FLOW 的 STG-04 五个方法接入格）**：对每一条待发布素材，逐市场扫「文案正文 + 五点描述 + 后台关键词 + 视频脚本文本」，把命中项落成可核验清单 —— 每条带声明类型与所需证据。
- 算式一（命中集）：`命中项 = { (素材, 目标市场, 声明类型, 命中位置, 所需证据) | 素材文本 ∩ 该市场的禁止与条件性声明词表 ≠ ∅ }`；源字段：〈平台后台〉的 Listing 字段与素材版本记录（`文案正文` / `五点描述` / `后台关键词` / `脚本转写` / `素材版本号`），〈合规条款库〉的 `市场` / `声明类型` / `条目` / `所需证据` / `生效版本`。声明类型只取条款库枚举，**本契约不自建第二张声明分类表**。
- 算式二（审查覆盖率）：`审查覆盖率 = 已扫描的 (素材 × 目标市场) 组合数 ÷ 同期进入本 FLOW 标准产物的 (素材 × 目标市场) 组合数`；分母逐 FLOW 取：FLOW-02 取〈新品验证证据包〉、FLOW-04 取〈市场进入包〉、FLOW-05 取〈服务与留存方案〉、FLOW-06 取〈数据/工具交付包〉、FLOW-07 取〈重大事件处置包〉里的素材市场清单。
- 取值：**审查覆盖率 = 100%**（进入标准产物的素材市场组合无一漏扫）；放行线 ＝ **未带证据的条件性声明命中数 = 0 条**（二值判定 —— 本契约把材料已命名的 `STG-06 Assurance 接收门禁`读成缺一项即 HOLD、无部分通过档；**这是本契约的读法，材料未给此口径**）。这两个数是**业务侧默认值**、不是实测值：依据是**经营者自述**「对外文案出去之前必须过一遍合规」。**替换条件** ＝ 〈合规条款库〉按市场接入并跑满 **1** 个完整自然季度之后，这两个数改由**实测漏扫组合数**与**实测命中分布**给出；尚未换法之前，措辞一律写作「本轮**未检出**漏扫」，写作「不存在违规」一律不许。
- **条件性声明的证据齐备性（可核验的配对，落五条 FLOW 的 STG-05 五个方法接入格）**：对每条条件性声明（如「经临床验证」「99.9% 抑菌」「有机认证」）逐条配对证据编号：`证据齐备率 = 已附证据且证据编号可核验的条件性声明数 ÷ 全部条件性声明命中数`；「可核验」定义为证据编号能在检测报告或认证证书原件上查到（原件由 §3 的岗位提供）。
- 取值：**证据齐备率 = 1.000（即 100%）**，本契约对缺项不设部分通过档；计数区间 ＝ **[0, 1]**（由〈合规条款库〉的必附证据清单直出，非固定常量）。**替换条件** ＝ 〈合规条款库〉逐市场写入必附证据清单后，改用「按清单逐项判定 + 逐项留痕」；替换前该值只作为送审前的自检项，**不得**替代主管签署。
- **AIGC 与合成内容的标注机检（落五条 FLOW 的 STG-04 与 STG-08 方法接入格）**：对 AIGC 生成或辅助生成的图文与视频逐条机检标注位与标记词是否齐备，输出 `标注缺失数 = 素材中「无标注位且无标记词」的条数`。
- 取值：**标注缺失数 = 0 处**；标注要求的原文与生效版本由 AGT-027 店铺账号健康与规则取回（§3），**以取回的原文版本为准，不以卡面或记忆中的政策为准**。**替换条件** ＝ 平台与市场的标注要求版本更新后按新版本重算；替换前标注缺失的素材只出 Action Intent，不进 STG-07。
- **扩召回档（词表未收录的同义变体，召回优先）**：对未命中的文本用语义相似度筛同义变体（如「帮助消化」对「改善肠胃」），`扩召回候选 = 相似度 ≥ 0.80 的片段`（**业务侧默认**起点，来源＝经营者自述「宁可多送几条去人工，也不能漏一条」）。
- 取值：语义相似度门槛 ＝ **0.80**；**召回优先于精确** —— 命中即入队、不设二次过滤阈值，误报由人工在队列里剔除（漏报的罚高于误报）；**替换条件** ＝ 词表覆盖满 **1** 个完整自然季度且人工复核累积 ≥ **500** 条判定后，改用「使漏报为 0 的最低相似度」替换；替换前扩召回候选一律标「扩召回候选、需人工判定」，**不得**直接写进违规结论。
- **本段的能力边界**：只做四件事 —— 命中了哪一条、条件性声明缺哪份证据、AIGC 标注缺在哪一条、按什么次序送人工；**不做合法性判定、不出法律结论、不签署放行**（见 §2 第 1 条）。
- 换入同族卡时同样要逐条剔除该卡自身的案例与实验数值。三张代表卡卡面带数字的段落如下，任一条都不得进入本业务口径：

## 2 不可达部分

- 不可达①（需**法定或治理签署**）—— 某条宣称在某市场是否违法、能否放行的最终判定与签署：规则与分类器只能给出「命中哪一条、缺哪份证据」，给不出法律定性。
  → 替代路径：由 AGT-044 产品合规与隐私的合规责任人签署〈合规矩阵与证据缺口〉并逐条写结论，涉争议、召回、对外声明的另由 AGT-043 法务与知识产权出法律意见；没签之前，本格把 `命中项` 与 `证据齐备率` 两列照出，第三列只写「结论待签」；签署结论到位后替换该列。在替换之前命中项不得进入 STG-07 受控动作，只能形成 NoActionRecord
- 不可达②（需**外部事实**）—— 各市场法规与平台政策的现行有效文本与生效版本号（FDA / FTC / ASA / ACCC / 欧盟各指令与平台品类专项限制）：对方单方发布、随时更新，本司只能取回执与原文。
  → 替代路径：由 AGT-044 与 AGT-043 按市场提供法规与平台规则原文、由 AGT-027 店铺账号健康与规则提供平台政策原文与生效版本号；原文未取回时，本格能算 `命中项` 与 `审查覆盖率`，但每条命中的「所需证据」栏只能引上一版条文并挂「引用版本早于现行」，改写建议随之只出候选；原文到位后按现行版本号重出该栏与改写建议。在此之前候选改写稿不得进 STG-05 定稿，相关素材降级为 NoActionRecord 并留人工工单
- 不可达③（需**实物或回执**）—— 检测报告、认证证书、临床或功效证据原件与批次追溯记录：证据齐备率的分子只能由原件证明，卡面与文案里的一句「已认证」不构成证据。
  → 替代路径：由 AGT-013 产品验证与研发项目提供验证结论、由 AGT-018 生产协同与质量控制逐 SKU 交出检测报告与批次追溯、由 AGT-044 核对证书原件与有效期；三样未齐时，条件性声明的 `证据齐备率` 分子只认能落到本批次报告编号的条数，其余标「证据未落本批」；本批报告与证书原件到位后逐条补编号并重算该比值。在补齐之前涉健康、成分、安全的宣称不进标准产物的可执行项
- 不可达④（需**外部事实**）—— 监管与平台的执法口径与个案裁量（同一句宣称在某市场实际被如何认定、有没有被投诉过）：属外部事实，本司系统内没有可复算字段。
  → 替代路径：由 AGT-044 组织当地法规顾问或外部律师出具逐市场意见，同业处罚与投诉案例由 AGT-007 市场竞争与机会研究提供；补不上时按**保守档**改稿（删去绝对化与功效表述、加免责与测试方法说明）并标「未经当地确认」；后果是保守档改稿只能用于内部预览，不得据此上架或投放。
- 不可达⑤（需**法定或治理签署 ＋ 需授权**）—— 涉合成人像、用户证言、儿童形象与个人信息使用的边界（能不能用某个 UGC 画面、能不能用某位用户的评价）：须隐私与授权判定，规则引擎只能识别文本。
  → 替代路径：由 AGT-044 出隐私判定、AGT-050 信息安全与权限出授权与取用结论、由 AGT-043 出肖像与著作权意见；三方结论缺任一时，画面素材按「不含可识别自然人」这一最窄版本重出，逐条挂「肖像与授权未判」标记；结论到位后按判定结果换成可用素材范围。在换成之前相关素材不上线，只挂 Action Intent 与人工工单

## 4 该格何时必须冻结

- 命中项未取得 AGT-044 合规责任人的签署结论（只有模型候选）⇒ 该素材不得推进到 STG-07 受控动作，只能形成 NoActionRecord。
- 条件性声明的证据齐备率 < **1.000**（缺一份原件或证书已过期）⇒ 该素材不得进入 STG-05 定稿，也不得上架。
- 审查覆盖率 < **100%**（存在已进入本案标准产物却未扫描的素材市场组合）⇒ 冻结该 Case 的内容部分，且不得据该清单出具「无违规」结论。
- 以未核验规则（无生效版本号的法规或平台政策文本）为依据的改写版文案 ⇒ 不得写入标准产物的可执行项。
- 命中涉儿童、健康、医疗、安全或绝对化表述，而无 AGT-043 的法律意见或 AGT-013 的验证结论 ⇒ 不得进入 STG-07，只能出 Action Intent + 人工工单。
- AIGC 或合成素材的标注缺失数 > **0** 处 ⇒ 该素材不得上线（含内部测试账号以外的任何对外发布）。
- 同一素材在 **≥ 2** 个目标市场命中不同要求，而未出「最低改动通用版」或未逐市场分版 ⇒ 不得逐市场上架（避免同一文案在多市场的风险叠加）。
- 含可识别真人画面或用户证言而 AGT-044 的隐私判定或 AGT-050 的授权结论缺失 ⇒ 该素材冻结，转人工裁决。
- 外部证据时限：自本案方案产物提交起，至该 Case Charter 已写明的观察窗截止日仍缺 §3 所列任一项必得证据 ⇒ 判 HOLD 并转人工，不得默认放行。
- 同一素材在同一观察窗内已有未回填的整改动作 ⇒ 不得重复送审；已成功动作不得随整单重跑。
- 本段落在规则格（STG-01 / STG-02 / STG-03 / STG-06 / STG-07）上的只是上列判据与门禁条件，不引入判别式或预测式。

## 5 数据要求（五维 · 三列）

| 维 | 取值 | 缺值处置（**取值为缺口时必填**：先用什么顶替 + 什么条件下换成什么） |
|---|---|---|
| ① 获取路径 | 平台后台（卖家后台的 Listing 字段、素材版本记录、账号健康与政策通知）＋ 需授权（〈合规条款库〉与法规、平台规则原文，经合规条款库与外部顾问取得）＋ 自有埋点（独立站商品页与内容页的宣称文本及其版本） | 非缺口。某市场若只拿得到顾问的口头意见、没有可留档的书面原文，本格先用上一次书面意见加平台后台公告快照拼一条来源记录并标「原文缺失」，顾问书面意见与监管原文到位后换掉这条记录。在换掉之前该市场的素材扫描结果只允许在本格内排队，不得进 STG-07，也不得写成「该市场没有违规表述」 |
| ② 粒度 | 素材 × 目标市场 × 命中片段（一条 = 一处命中，带位置与所属字段）；图片与视频到帧或页面区块。**画面内文字本业务暂无逐帧抽取文本**（只有字幕与脚本文本） | 缺口：本维少了「画面内文字」这一块。主图、A+ 图与视频画面里贴上去的绝对化表述，现在既不在 `文案正文` 也不在 `五点描述` 里，`命中项` 集与 `审查覆盖率` 的分母都够不着它 —— 于是「这个素材的宣称都审过了」这句话在本业务站不住。先用字幕与脚本转写加上按比例抽帧人工核对顶住并标「画面文字未覆盖」，画面 OCR 或多模态逐帧识别接入后换成逐帧文本。在此之前含画面文字风险的素材必须在〈市场进入诊断〉里点名，不得声称画面已审 |
| ③ 回溯深度 | 近 2 个完整年度（业务处境给出的出海历史长度，决策 Q11），用于统计历史命中与整改工单量；〈合规条款库〉自其建库日起算 | 非缺口。某市场上线晚、或〈合规条款库〉建库晚，攒不到两年记录时，本格先用该市场上线日（或建库日）到昨日的全部命中与整改工单暂按基线并标「窗长不足」，攒够 **2 个完整年度**后改用完整窗的命中分布。在改用之前 `审查覆盖率` 照常逐案算，但跨年同比与「按历史命中率给该市场定风险档」这两件事都不出 |
| ④ 新鲜度 | 每次进入 STG-04 证据收集前重读条款库与政策原文；法规与平台规则按变更事件触发重读并记录生效版本号；进入 STG-06 前须为「截至前一日 24:00」的完整快照 | 非缺口。政策变更若只能靠人每周巡一遍，命中项与生效日之间就会差出几天，`标注缺失数` 与声明词表都可能落后一个版本；此时先用上次重读日加公告订阅邮件暂按重读点并标「巡检节奏」，订阅或推送通道接上后按变更事件触发重读。在接上之前，命中项交人工时一律按可能已过期处理，涉新规的素材一律不自动放行 |
| ⑤ 口径归属 | AGT-045 指标契约与主数据（市场、渠道、素材、SKU 对象的标识，宣称分类与覆盖率、证据齐备率的分子分母与时间归属）；每条记录随带 AGT-046 的质量状态、来源与新鲜度 | 非缺口。声明类型枚举与 `审查覆盖率` 的分子分母没有进主数据时，本格先照〈合规条款库〉现有的那几类声明名逐条挂「枚举待归位」标记，`AGT-045` 定名后改用映射表归位并重算覆盖率。在归位之前这套分类只在本格内给素材排队，既不上报合规结论，也不算进绩效口径 |
