# 内容策划 · 供给契约

> **本契约的两部分，用法不同。** §1 / §2 / §3 / §5 / §6 是**作业口径** —— 据此产出方案：
> 可达段给算式与取值，不可达段给替代路径。§4 是**放行判据** —— 它规定的是「什么条件下不许自动走」，
> **不得整句抄成交付物内容**。
>
> 本责任的判定理由（`_survey_org_model.md` §F.3）：**内容可生成与排序优化，但选题与主张需品牌与合规判断** ——
> 这句话就是本契约可达段与不可达段的分界线。
>
> **取值来源纪律（全文适用）**：本契约出现的阈值、比例与时限只有三种来源 ——
> （a）材料已给出的数（出海历史 2 个完整年度＝决策 Q11；经营节奏「月度经营复盘」＝1 个自然月；
> 渠道构成 Amazon 65% / 独立站 15%、其余 20% 未定名＝开放事实 O1）；
> （b）业务侧默认（经营者自述 / 平台规则 / 行业惯例，逐条附替换条件）；
> （c）§1 算式的输出（由命名的数据系统直出）。候选卡卡面的示例数字**不构成**第四种来源。
>
> **方法族与本契约的关系**：本契约按「责任」建、不按「卡」建。代表卡（`p2s-a-plus-content-template-engine` 的
> VOC 洞察驱动模块化内容方案、`p2s-tiktok-hook-optimizer` 的开场钩子特征打分与排序、
> `Skill-LLM-Personalized-Marketing-Copy-Generation` 的按画像分层可控属性文案生成）只提供方法族骨架；
> 三条算式里的每一个输入都来自本司命名系统，卡面数字一条都不进本业务口径。

## 1 算法可达部分

- **内容选题的排序分（可核验的排序）**：把「下一个内容周期该做哪些主题」变成一张按分排序的主题表，输入全部来自本司已有系统；主题归并一律取 AGT-006 听澜的 VOC 主题树，本契约**不自建第二张主题表**。
- 算式一（主题需求热度）：`热度_i = 主题 i 在〈平台后台〉Amazon 品牌分析搜索词报告与〈自有埋点〉独立站站内搜索词中的近 2 个完整年度曝光量之和 ÷ 同窗两渠道全站搜索曝光量之和`。
- 算式二（内容覆盖缺口）：`缺口_i = 1 − 该主题已有可售 A+ 模块／详情页内容段／独立站内容页的覆盖率`；覆盖率按〈平台后台〉的商品内容字段与〈自有埋点〉的内容页会话数算，同一主题在三个渠道取并集。
- 算式三（排序分）：`排序分_i = 热度_i × 缺口_i`，按降序出表。
- 取值：内容周期取材料已定名的经营节奏**月度经营复盘**（1 个自然月）为一个周期，每周期取排序分降序的**前 20 个主题**进候选池。
- 阈值：进候选池需同时满足**热度 ≥ 1%** 与**缺口 ≥ 0.5**；「前 20」与这两个门槛均为**业务侧默认**（来源＝经营者自述：一个月的内容产能上限约 20 个主题，主题在全站搜索曝光中占比不足 1% 不值得单独出一版内容）。
- 替换条件：〈平台后台〉与〈独立站埋点〉跑满 2 个完整年度、且 AGT-045 同尺签发内容主题口径后，门槛改用**上一年度同期主题热度分布的第 75 百分位**，候选池上限改用 AGT-031 绘影当期可交付素材数反推；替换前排序结果只用于内部排期，不得写成对外内容承诺。
- **内容版本的齐备性与受限词前置机检（可核验的计数）**：对每个待发布内容版本逐字段检查，并按〈平台后台〉账号健康与政策通知里的受限词表做词面命中。
- 算式：`字段齐备率 = 非空必填字段数 ÷ 必填字段总数`；`违规命中数 = 待发布内容文本 ∩ 受限词表 的词面命中条数`。必填字段集取 FLOW-04/STG-05 标准产物〈市场进入包〉中「本地化内容」一节的字段清单（由 AGT-028 译境维护）与 FLOW-01/STG-05〈联合经营行动包〉的内容项字段（由 AGT-045 维护），本契约不另造字段名。
- 取值：**字段齐备率 = 1.000（即 100%）**、**违规命中数 = 0 条**，两者同时满足才允许把该版本写进〈联合经营行动包〉的可执行项。
- 替换条件：受限词表以 AGT-027 守店取回的平台政策原文版本号为准；未取回期间本段只判字段齐备率，违规命中数一律出「版本未取回」标记（见 §2 第 3 条），该标记不因计数为 0 而消失。
- **同主题内容版本的描述性排序（不构成因果结论）**：按同一主题下已发布版本在〈平台后台〉与〈独立站埋点〉的读数算 `曝光加权点击率 = 点击量 ÷ 曝光量` 与 `会话到加购转化率 = 加购会话数 ÷ 内容页会话数`，输出该主题内的版本序。
- 取值：排序只收**同主题、同渠道、同语言**三个同口径条件齐备的版本，缺一条不入表；入表版本按两指标各自的降序给出名次，两指标名次冲突时不合成总分，只并列报出。
- 基线：**单版本曝光 < 1,000 次 或 内容页会话 < 100 次**时不入排序表，改出「样本不足」标记（业务侧默认，来源＝经营者自述：单版本曝光不足 1,000 次时点击率在两次拉数之间摆动超过 1 个百分点）。
- 本段的能力边界：只做三件事 —— 主题排序、字段齐备性与受限词命中、同主题版本的描述性排序；**不产出品牌主张、不产出合规结论、不产出内容增量归因**（三条都在 §2）。
- 本契约对同族方法卡通用；换卡时只替换方法实现，其余要求不变。

## 2 不可达部分

- 品牌主张与叙事口径的最终定调：本契约的方法只能给候选叙事角度与排序，定调属 **AGT-029 立言（品牌战略与传播）的治理签署**，不可由本段产出。
  → 替代路径：由 AGT-029 在 FLOW-01/STG-05 与 FLOW-04/STG-05 方案定稿前签署〈品牌主张卡〉；补不上时先用上一版已生效的品牌主张顶替并逐条标「未定调、不得对外」，新叙事只进 Action Intent、不进 FLOW-01/STG-07 与 FLOW-04/STG-07 的受控动作；后果是本期只做存量主题改写，不开新叙事。
- 母婴品类功效宣称的事实依据：属**外部事实＋实物证据**（检测报告、认证原件），本司系统内没有可复算字段，内容里的功效表述不能由本段推出。
  → 替代路径：由 AGT-013 求证在 STG-04 结束前提供检测报告与认证编号、由 AGT-044 安界在方案定稿前给合规判定；补不上时先用「已上市同类商品的公开宣称＋认证编号」顶替并逐条标「未核验」，凡含功效、医疗或绝对化表述的内容一律不出稿；后果是该主题本期只出非宣称类内容，且不得进入上架动作。
- 平台政策原文与受限词表的生效版本：属**外部事实**（平台单方发布、随时更新），本司只能取回执、不能改。
  → 替代路径：由 AGT-027 守店在 FLOW-01/STG-06 与 FLOW-04/STG-06 前提供政策原文与生效版本号；补不上时先用〈平台后台〉当日可见的受限词表快照顶替并标「版本未取回」，命中未核验词表的版本只出 Action Intent ＋ 人工工单；后果是该版本不进本周期上架动作。
- 母语在地表达与文化适配的裁决：需**母语专家的治理签署**，机器译稿不能自证在地性，也不存在可复算的地道度指标。
  → 替代路径：由 AGT-028 译境在方案定稿前逐条签署本地化内容；补不上时先用机器译稿加上一版已上线译法做成「待签」双栏并标「未过在地语言核对」；后果是目标市场内容只做独立站内部预览，不得进入上架动作。
- 内容增量的因果归因：本业务**独立站 holdback 没有、可以建但需先建**（决策 Q10 已定），建成前本格不得输出因果性内容结论。
  → 替代路径：由 AGT-035 试真在 holdback 建成后提供分组对照读数；建成前先用「内容上线前后同口径的自然流量与转化的描述性对比（含同期大盘对照）」顶替，结论一律标「非因果、仅描述」；替换条件＝holdback 上线后改用分组对照，替换前该读数不得写进 FLOW-01/STG-08 的〈经营关闭记录〉效果结论。

## 4 该格何时必须冻结

- 〈品牌主张卡〉未由 AGT-029 在方案定稿前签署（首版内容或新叙事主题）⇒ 该版本不得进入 FLOW-01/STG-07 与 FLOW-04/STG-07 的受控动作，只能形成 NoActionRecord。
- 字段齐备率 < 1.000，或受限词表版本未取回而内容仍按「命中数为 0」放行 ⇒ 该版本不得写进〈联合经营行动包〉的可执行项，FLOW-01/STG-06 与 FLOW-04/STG-06 的接收门禁判 HOLD。
- 内容含功效、医疗或绝对化表述，而 AGT-013 的检测报告或 AGT-044 的合规判定缺失 ⇒ 不得出稿，也不得进入上架动作。
- 目标市场语言版本未过 AGT-028 的在地签署 ⇒ 该市场内容不得进入 FLOW-04/STG-07 的上架尝试，转人工裁决。
- 同主题版本排序中带「样本不足」标记的版本仍被写成「最优版本」结论 ⇒ 该结论不得进方案，也不得作为〈经营关闭记录〉的效果结论。
- 内容效果被表述为因果结论而 holdback 尚未建成（决策 Q10）⇒ 该表述不得进入任何对外内容，也不得写进〈经营关闭记录〉。
- 外部证据时限：自〈联合经营行动包〉或〈市场进入包〉提交起，至该 Case Charter 已写明的观察窗截止日仍未取得 §3 所列任一必得证据 ⇒ 判 HOLD 并转人工，不得默认放行。
- 本段落在规则格（FLOW-01/STG-01、STG-02、STG-03、STG-06、STG-07 与 FLOW-02、FLOW-04 的同名阶段）上的只是判据与门禁条件，不引入判别式或预测式。

## 6 适用 FLOW
