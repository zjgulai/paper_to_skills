# 市场语境审查 · 供给契约

> **本契约的两部分，用法不同。** §1 / §2 / §3 / §5 / §6 是**作业口径** —— 据此产出方案：
> 可达段给算式与取值，不可达段给替代路径。§4 是**放行判据** —— 它规定的是「什么条件下不许自动走」，
> **不得整句抄成交付物内容**。
>
> 本责任的判定理由（`_survey_org_model.md` §F.3）：文化/合规风险可用多语分类器预筛，
> 但**当地理解须本地证据** —— 这就是本契约可达段与不可达段的分界线。
>
> **取值来源纪律（全文适用）**：本契约出现的每一个阈值、比例与时限，来源只有三种 ——
> （a）业务处境或材料已给出的数（出海历史 **2 个完整年度**＝决策 Q11；渠道构成 Amazon **65%** / 独立站 **15%**，
> 其余 **20%** 未定名＝开放事实 O1；经营节奏「月度经营复盘」＝**1** 个自然月、「季度经营策略」＝**1** 个自然季度）；
> （b）业务侧默认（经营者自述或行业惯例，逐条附替换条件）；
> （c）§1 算式由命名数据系统直出。
> **卡上的案例数字不构成第四种来源**（逐条清单见 §1 末）。

## 1 算法可达部分

- **跨语言内容风险预筛（命中式扫描）**：对每一条待上线素材，逐市场扫「文案正文 + 图片描述」，把命中项落成可核验清单，供本地复核排队。落 FLOW-01/STG-04、FLOW-02/STG-04、FLOW-04/STG-04、FLOW-05/STG-04 四个 M 格。
- 算式一（命中集）：`命中项 = { (素材, 目标市场, 触发条目, 命中位置) | 触发条目 ∈ 〈各市场文化敏感词与禁忌词表〉按市场切片，且出现在该素材的文案正文或图片描述中 }`；源字段：〈产品文案与素材库〉的 `文案正文` / `图片描述` / `素材版本号`，〈各市场文化敏感词与禁忌词表〉的 `市场标识` / `条目` / `类型`。
- 算式二（预筛覆盖率）：`预筛覆盖率 = 已扫描的 (素材 × 目标市场) 组合数 ÷ 同期进入本 FLOW 标准产物的 (素材 × 目标市场) 组合数`；分母逐 FLOW 取：FLOW-01 取〈联合经营行动包〉、FLOW-02 取〈新品验证证据包〉、FLOW-04 取〈市场进入包〉、FLOW-05 取〈服务与留存方案〉里的素材市场清单。
- 取值：**预筛覆盖率 = 100%**（进入标准产物的素材市场组合无一漏扫）；**放行线 = 命中 0 条**（二值判定，不设部分通过档）。这两个数是**业务侧默认值**、不是实测值：依据是**经营者自述**「新市场与新素材上线前必须过一遍文化审查」，且与材料已定名的 STG-06 接收门禁口径一致（该门禁为**二值门禁**，缺一项即 HOLD、不设部分通过档）。**替换条件**：〈产品文案与素材库〉接入并覆盖满 1 个完整自然季度后，改用**实测漏扫组合数**与**实测命中分布**重算；替换前该结论只能表述为「**未检出**漏扫」，**不得**表述为「不存在文化风险」。
- **目标语言冷启动分类（少样本段）**：新市场评论与咨询语料稀少时，用源语言（英语）语料作源域、目标语言每类少量标注作支持集做原型分类，把目标语言文本归入可判定的粗类（如「正面 / 负面 / 使用与安装问题」）。该段的输出只用于**发现线索与排队**，不用于下结论。
- 取值：**支持集规模 = 每类 5–10 条、每个新市场合计 15–30 条**（**业务侧默认**，来源＝经营者自述的标注预算：单一市场外包标注不超过 **30** 条）；该规模下产出一律标注「冷启动期口径」。**替换条件**：〈平台后台〉评论与〈自有埋点〉咨询在目标语言累积到每类 ≥ **200** 条后，改用全量监督口径，不再用原型分类的冷启动口径；替换前不得据该粗类给出市场结论。
- **本段的能力边界**：只做三件事 —— 命中项是否落在词表、预筛是否覆盖全、粗类线索是否成队列；**不产出「当地是否会冒犯」的判断、不产出合规结论、不签署上线放行**（见 §2）。落 FLOW-01/STG-05、FLOW-02/STG-05、FLOW-04/STG-05、FLOW-05/STG-05 四个 M 格时，交付物里只有队列与清单。
- 本契约对同族方法卡通用；换卡时只替换方法实现，其余要求不变。
- 换入同族卡时同样要逐条剔除该卡自身的案例与实验数值。三张代表卡卡面带数字的段落如下，任一条都不得进入本业务口径：

## 2 不可达部分

- 当地文化语用判断（同一句文案在当地是否真的冒犯、冒犯到什么程度、改写后是否仍然自然）：属**人的专业判断与外部事实**，词表与分类器只能给出「与已知禁忌条目字面相关」，给不出「在当地语境里是否成立」。
  → 替代路径：由 AGT-028 本地化与市场适配在 STG-06 接收门禁前组织目标市场母语审校（当地团队或外部服务）出具逐条意见；补不上时先用「词表命中清单 + 上一版已放行素材的对照」顶替，并在标准产物里逐条标注「未经本地复核」；后果是命中项未复核的素材不得进入 STG-07 受控动作，只能形成 NoActionRecord。
- 法规与平台规则的现行有效文本（FDA/FTC/ASA/UCPs/BCAP 原文与生效版本号、平台母婴品类专项限制原文）：属**外部事实**，本司系统内不存在可复算字段。
  → 替代路径：由 AGT-044 产品合规与隐私（准入与宣称判定）与 AGT-027 店铺账号健康与规则（平台政策原文与生效版本）在 STG-04 结束前提供；补不上时先用「平台后台公告截图 + 上一次已生效版本号」顶替并逐条标「未核验」；后果是以未核验规则为依据的改写版文案不得进入 STG-05 定稿，相关对象降级为 NoActionRecord 并留人工工单。
- 实物与报告级证据（检测报告、认证证书、批次追溯记录、标签实物）：属**实物或回执**，无法由词表或分类器推出。
  → 替代路径：由 AGT-044 与 AGT-018 生产协同与质量控制按 SKU 提供检测报告与批次追溯、由 AGT-013 产品验证与研发项目提供验证结论；补不上时先用「供应商自述 + 上一批次同类报告」顶替并标「非本批证据」；后果是宣称类内容（健康、成分、安全）在证据补齐前不得写入标准产物的可执行项。
- 账号与主体级合规责任（谁对该市场的账号与内容负最终责任、对外声明的边界）：属**法定或治理签署**。
  → 替代路径：由 AGT-027 在 STG-06 前出具账号责任人与政策适用范围确认，AGT-043 法务与知识产权在涉对外声明的定稿前出具意见；补不上时由 AGT-001 经营目标与资源统筹指定临时责任人并留痕；后果是责任人未定的 Case 其接收门禁判 HOLD，且不计入本周期市场语境审查覆盖率。

## 4 该格何时必须冻结

- 定稿前未取得目标市场母语审校意见，而预筛命中项 ≥ 1 条 ⇒ 该素材不得推进到 STG-07 受控动作，只能出 NoActionRecord。
- 预筛覆盖率 < 100%（存在已进入本 FLOW 标准产物却未扫描的素材市场组合）⇒ 冻结该 Case 的内容部分：相关素材不得进入上架动作，且不得据该清单出具「无风险」结论。
- 以未核验规则（无生效版本号的平台政策或法规文本）为依据的改写版文案 ⇒ 不得写入〈市场进入包〉的可执行项。
- 宣称类内容涉及健康、成分或安全，而 AGT-044 的宣称判定或检测报告缺失 ⇒ 不得进入 STG-07，只能出 Action Intent + 人工工单。
- 命中项涉及当地宗教、颜色、数字或图像禁忌，当地母语审校判「须修改」而未改 ⇒ 该 SKU 在该市场的上架动作冻结。
- 账号责任人未确认（AGT-027 未出确认、AGT-001 亦未指定替代责任人）⇒ 该 Case 的 FLOW-04/STG-06 接收门禁判 HOLD。
- 外部证据时限：自定稿产物提交起，至该 Case Charter 已写明的观察窗截止日仍未取得 §3 所列任一项证据 ⇒ 判 HOLD 并转人工，不得默认放行。

| ⑤ 口径归属 | AGT-045 指标契约与主数据（市场、渠道、账号、素材对象的标识与口径）；每条记录随带 AGT-046 的质量状态、来源与新鲜度 | 非缺口。若指标契约尚未签发上述对象口径：先按〈市场进入 Case Charter〉已写明字段暂按口径并逐条标「口径未签发」；契约签发后替换，替换前该口径只用于排序与内部判断，不进入对外表述 |
