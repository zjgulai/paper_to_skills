# 安全事件处理 · 供给契约

> 本契约分两部分：§1 / §2 / §3 / §5 / §6 是**作业口径**（据此产出方案：可达段给算式与取值，不可达段给替代路径）；
> §4 是**放行判据**（门禁方与人工使用），**不得**整句抄成交付物内容 —— 它规定的是「什么时候不许自动走」。

## 1 算法可达部分

- 本契约对同族方法卡通用；换卡时只替换方法实现，其余要求不变。同族方法卡：`p2s-agenttrust-runtime-safety-interception`（运行时安全拦截判决：命令归一 → 前序操作链判语义 → 判决 + 安全替代写法 + 审计记录）与 `p2s-cross-border-payment-fraud-detection`（多源信号图风险评分：账号 / 设备 / 地址 / 支付凭证的关联与分流）。
- 可达段＝这条责任里「事件的**检测与分类**」那一段（判定理由原文：事件检测与分类可算法化）：逐次工具调用 / 访问请求的在线判决（ALLOW / BLOCK / HOLD）与命中红线时的替代写法，以及按主体聚合出的「越权拒绝」与「授权漂移」两项清单 —— 材料为 AGT-050 定的验收度量正是这两项。
- 算式一（在线，逐次判决）：按〈Agent 工具调用与权限判定日志〉取 调用主体 / 工具名 / 目标对象 / 前序操作序列，与〈安全事件处置策略〉的红线清单逐项匹配，`风险分 = 命中红线项的档位之和 ÷ 红线清单档位总和 × 100`；判决规则：命中任一红线项（风险分 > 0）⇒ BLOCK，仅命中观察项 ⇒ HOLD 并转 AGT-050 人工复核，均未命中 ⇒ ALLOW。**各红线的档位值取〈安全事件处置策略〉里该红线的既有档位，本契约不另赋权**（避免把别处的实验权重移植成本业务取值）。
- 取值一：风险分区间取 0–100 分、判决档位取三档（红线档 / 观察档 / 放行档）；红线档与观察档的边界由〈安全事件处置策略〉的清单归属唯一决定，不另设分数切点；红线清单的判据覆盖目标取 **15/15 = 100%**（15 类取自材料为 FLOW-07 已定名的异常回放场景：误报、零匹配、多匹配、残缺 Case、非权威信号、事务中断、Outbox 重复派发、TTL 过期、模型改参、紧急通道尝试恢复等）。
- 算式二（按主体，每日）：`越权拒绝率 = 当日 BLOCK 判决次数 ÷ 〈权限矩阵与访问证据〉当日在册的授权条目数`；`授权漂移项数 = 在册授权条目中「实际调用对象 ∉ 该条目授权范围」的条目数`。
- 取值二：判决阈值（越权拒绝次数）取 **0 次** —— 默认拒绝、零容忍，取自信息安全行业惯例，任何一次 BLOCK 判决当日即生成一条安全事件记录。本业务暂无历史基线（判决日志尚未沉淀满一个完整周期）：〈Agent 工具调用与权限判定日志〉满 **1 个完整自然月**后，替换为该月各周 BLOCK 占比的 P95 分位；替换前该阈值只用于内部拦截与事件建单，不得作为对外披露的「事件率」或考核口径。
- 不得移植（同族卡内的实验参数，一律不写成本业务取值）：拦截准确率 95%、判决延迟 < 1ms、欺诈率 3–8%、单笔拒付损失 $334、检测率 85–90%、年化收益 20–60 万元、启发式权重 0.15 / 0.25 / 0.20 / 0.30 / 0.35、转运地址邮编清单等 —— 它们是别处的实验条件与示例数据，本契约的取值只来自上面两条算式与〈命名数据系统〉。

## 2 不可达部分

- 需法定与治理签署：隔离范围、恢复、重新开放、扩大范围、外部承诺、退款、召回、销毁与永久变更的**决定本身**。可达部分只到「候选动作 + 证据包 + 影响范围」，签署不在本层；材料规定这些动作只能在正常的 FLOW-07/STG-07 执行。
  → 替代路径：由该 FLOW 的结果负责人（质量事件 AGT-018、账号事件 AGT-027）在 STG-07 签署，AGT-050 在 STG-06 的 Assurance 接收门禁前出具安全意见；签署未到位时**先只执行已发布规则允许的保护动作**（Emergency Guard 的最小范围冻结 + Policy DENY/HOLD，TTL 内），后果是恢复类动作整体顺延、影响范围在 TTL 到期时重新评估且不自动恢复。
- 需外部事实（平台侧）：账号级风险判定理由、封店与资金冻结依据、申诉裁决结果，均由平台内部规则裁决，本业务拿不到其判据原文。
  → 替代路径：由 AGT-027 在 STG-04 建诊断前提交平台通知原文与申诉材料、按平台回执更新；拿不到内部判据时**先用**「平台通知原文 + 历史同类申诉结果」**顶替**事件分类依据，并把分类标注为「待平台回执复核」；后果是影响范围只能按已到手回执界定，不得声称已闭环。
- 需实物或回执：货物是否已销毁、召回是否送达、仓库是否已隔离、账号是否已实际停用 —— 只有逐对象回执能证明，日志里只有「已下达」。
  → 替代路径：由 AGT-018 与 AGT-020 在 STG-08 前提供销毁记录、召回签收与仓库隔离单，账号侧由 AGT-027 提供平台回执；回执未到前**先用**「动作已下达」的执行记录**顶替**并标记为未闭环；后果是事件不得关闭、也不得进入异步学习。
- 需外部事实（司法与法域）：电子证据固定、日志完整性证明、是否构成刑事或民事追责，需第三方取证或司法鉴定。
  → 替代路径：由 AGT-043 在 STG-05 前组织争议证据、必要时委托外部鉴定或报执法机关；未拿到前**先用**〈Agent 工具调用与权限判定日志〉的只读副本（带哈希与时间戳）**顶替**，仅作内部根因与恢复依据；后果是该副本不得作为对外追责、披露或索赔依据。
- 需法定披露判断：是否向消费者、平台或监管告知、以什么口径与什么时限告知，属法定与治理判断（数据泄露告知义务、隐私要求），不是风险分能推出的结论。
  → 替代路径：由 AGT-044 在 STG-06 前给出适用法域的披露口径与时限、AGT-042 给跨境实体口径；未给出前一律**先按最严静默口径**（不对外承诺、不发布、只做保护动作）**先行**，后果是由 AGT-043 事后**补正**对外时效，补正成本与合规风险由该 Case 承担。

## 4 该格何时必须冻结

- 事件分类所需证据缺任一项（平台通知原文 / 受影响对象清单 / 该主体的在册授权条目）时，该格不得推进到 FLOW-07/STG-07 的受控动作。
- 命中已发布紧急规则的信号在绑定前不唯一（零匹配或多匹配、范围或 Policy 不唯一）时：只记 Pre-Case Exception，不得创建 Guard Decision、残缺 Case 或任何动作记录，信号范围就地冻结。
- Policy 判决为 DENY 或 HOLD 时不产生 Outbox；TTL 过期禁止首次执行，也不自动恢复。
- 逐对象权威回执（销毁 / 召回签收 / 仓库隔离 / 平台账号回执）未齐时，事件不得关闭，也不得进入 STG-08 的异步学习。
- 同一主体当日出现任一次红线档判决（越权拒绝次数 > 阈值 0 次）时，立即冻结该主体的写入类动作，直到 AGT-050 复核并重新签发授权条目。
- 对外披露、外部承诺、退款、召回、销毁与永久变更只能在 FLOW-07/STG-07 执行；在此之前一律冻结，不得由任何上游阶段代为执行。
