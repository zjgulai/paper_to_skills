# 质量分析 · 供给契约

> **本契约的两部分，用法不同。** §1 / §2 / §3 / §5 是**作业口径** —— 据此产出方案，并把规则落实成方案里的取值。
> §4 / §6 是**放行判据** —— 它们规定的是「什么条件下不许自动走」，**不得整句抄成交付物的内容**。
>
> 本责任的判定理由（`_survey_org_model.md` §F.3）：SPC 控制图、过程能力指数与根因相关分析是成熟质量统计方法。
> 方法既然成熟，本契约的重点就不在「算不算得出来」，而在**算出来的判据在哪个阶段只准预警、在哪个阶段才准动作**
> —— 这正是 §6 写得比 §3 更长的原因。
>
> 岗位 AGT-018 生产协同与质量控制（DOM-03 / PLN-OPS），岗位产物「质量事件与纠正措施包」，
> 结果指标「缺陷复发与处理时效」，适用 FLOW-02 新品需求到商业验证、FLOW-03 补货采购与交付、FLOW-07 重大质量与账号事件。
>
> **本契约覆盖的格**：方法格 = FLOW-02/STG-04、FLOW-02/STG-05、FLOW-02/STG-08、FLOW-03/STG-04、FLOW-03/STG-05、FLOW-03/STG-08、FLOW-07/STG-04、FLOW-07/STG-05、FLOW-07/STG-08（§3 的 L1–L4 落在这些格上）；
> 规则格 = 同样三跳的 STG-01／STG-02／STG-03／STG-06（Assurance 接收门禁）／STG-07（受控动作），
> **这些格只放判据与门禁条件，不接入任何判别式或预测式**（§6 的落脚处）。
>
> **取值来源纪律（全文适用）**：本契约出现的每一个阈值、比例与时限，来源只有三种 ——
> （a）业务处境或材料已给出的数（出海历史 **2 个完整年度**＝决策 Q11；经营节奏「月度经营复盘」＝**1** 个自然月；
> 渠道构成 Amazon **65%** / 独立站 **15%**，其余 **20%** 未定名＝开放事实 O1）；
> （b）业务侧默认（经营者自述或行业惯例，逐条附替换条件）；（c）§3 算式由命名数据系统直出。
> **候选卡卡面上的案例数字与模拟分布不构成第四种来源**（逐条清单见 §1）。

## 3 标定规则

- 取值来源：自有埋点（Case/Event Ledger 的质检判定与事件记录）＋平台后台（Amazon 卖家后台报表、库存台账）＋需授权（来料检验台账、供应商质量档案、采购台账）；**不引用卡内任何案例数字**（清单见 §1）。
- **L1 控制限与特殊原因判定（本契约的取值出口）**：以「供应商 × 物料」为一条序列，逐批算 `不合格率 p_i = 该批不合格数 ÷ 该批抽样数`；中心线取**加权**口径 `p̄ = Σ不合格数 ÷ Σ抽样数`（不是各批不合格率的简单平均 —— 各批抽样数不等时简单平均会把小样本批放大）；控制限 `UCL/LCL = p̄ ± 3 × √(p̄ × (1 − p̄) ÷ n_i)`，`n_i` 为该批抽样数。
- 取值：控制限倍数 = **±3σ**（**业务侧默认**，来源＝行业惯例的休哈特控制限）；判异准则 = 点落在控制限外，**或**连续 **7** 点位于中心线同侧 / 呈单调趋势（**业务侧默认**，来源＝行业惯例的判异准则）；建图门槛 = 子组 **≥ 20** 组**且**单批抽样数 **≥ 50** 件，两条件缺一不出控制限。这三个数取自业务侧默认，**不是**卡面参数的换算。
- L1 替换条件：来料检验台账跑满 **2 个完整年度**（决策 Q11）后，中心线改用同「供应商 × 物料」实测不合格率分布的 **P50**、上限改用该分布的 **P99.7**；替换前控制限只用于预警排序与加严检验的触发，**不得**单独作为拒收、索赔或停货依据。
- **L2 过程能力与规格限**：`Cpk = min(USL − μ, μ − LSL) ÷ (3σ)`，`USL / LSL` 取该 SKU 的规格书；同批复算 `Cp = (USL − LSL) ÷ (6σ)` 用于区分「中心偏移」与「波动过大」（`Cp` 够而 `Cpk` 不够 ⇒ 先查偏移，不先换供应商）。
- 取值：过程能力受控线 = **Cpk ≥ 1.33**（**业务侧默认**，来源＝行业惯例的能力充足下限档）；**Cpk < 1.00 判能力不足、必须整改**；规格上下限未随产品定义或〈新品验证证据包〉给出时，**Cpk 一律不出值**，只出 L1 的结论。
- L2 替换条件：品类规格书与验证报告到位后，改用该规格书的实测 `USL / LSL` 与实测 `σ` 重算；替换前 Cpk 只在**同一供应商同一物料**内纵向比较，不跨品类、不跨供应商比较，也不用于对供方的正式索赔。
- **L3 主缺陷与根因相关分析**：`缺陷占比_d = 该缺陷类型不合格数 ÷ 当期不合格总数`，按占比降序累计，取累计占比达线的前若干类为**主缺陷**；对主缺陷按批次排序找**时间切点**，算切点前后不合格率差 `Δ = p_后 − p_前`，并把同一时点上「物料 / 工艺 / 产线 / 包装 / 承运方式」的变更项与 Δ 关联，输出「切点 ＋ 变更项 ＋ 置信度」三元组作为根因候选。
- 取值：主缺陷取**累计占比 ≥ 80%** 的前若干类（**业务侧默认**，来源＝行业惯例的柏拉图口径）；根因候选置信门控 = **0.70**（**业务侧默认**，来源＝经营者自述「七成把握以上才动手」）；**同一时点变更项 ≥ 2 项时，根因候选一律标「混杂未排除」**，不得收敛为单一根因。⚠️ 卡面 `p2s-return-root-cause-attribution-graph` 也写 **70%**，那是**卡页案例口径**，**不作为本取值的来源**（见 §1 清单第 11 条）。
- L3 替换条件：本司根因候选的人工复核记录（由「纠正预防措施」责任的 8D 台帐累积）满 **20** 例后，置信门控改用该 **20** 例中「人工确认为真」候选的最低置信度；替换前达线候选只能打可疑标并发起复检，**不得**据此拒收、索赔或扩大冻结范围。
- **L4 质量成本与供应商评级**：`COPQ = 返工重检成本 ＋ 退货重发成本 ＋ 客诉处理成本 ＋ 退货处置成本`，四项分别取命名源的直出字段（返工重检 = 不合格数量 × 单位返工工时 × 工时费率，工时费率取 AGT-041 口径；退货重发与实际承运账单一致）；`批次接收率 LAR = 接收批次数 ÷ 到货批次数`；供应商质量评级由 `LAR`、`COPQ ÷ 该供应商同期采购额`、**缺陷复发率**（同一缺陷族在整改后重现的比例）三项定档。
- 取值：评级分档 = **LAR ≥ 99% 且 COPQ 占比 ≤ 1% 判 A 档；LAR 95%–99% 或 COPQ 占比 1%–2% 判 B 档；其余判 C 档**（**业务侧默认**，来源＝经营者自述「批次接收率做到 99 以上才算稳定」）；C 档供应商或 C 档物料进**加严检验**，抽样数取常规的 **2 倍**，加严期连续 **5** 批合格才回到常规抽样（**业务侧默认**）。
- L4 替换条件：采购台账与检验台账跑满 **2 个完整年度**后，A/B 与 B/C 的分界改用同品类实测 `LAR` 与 `COPQ` 占比的 **P50 / P25**；替换前 C 档只触发加严检验与供应商评审工单，不触发暂停采购、扣款或索赔。
- **L5 产出（本规则定值的字段）**：以下标准产物里由上文四条规则定值的字段如下。
- FLOW-02/STG-04 的〈机会与可行性诊断〉：新供应商 / 新物料的历史批次接收率、过程能力结论与质量侧证据缺口由 L1、L2 定值。
- FLOW-02/STG-05 的〈新品验证证据包〉：试产批次的抽样数、接收准则档（常规 / 加严）与验收判据由 L1、L4 定值。
- FLOW-02/STG-08 的〈新品验证关闭记录〉：试产实测不合格率、`Cpk` 与是否达标由 L1、L2 定值。
- FLOW-03/STG-04 的〈供需证据与约束诊断〉：在途与在库批次的质量风险等级（可售 / 待复检 / 可疑）由 L1、L3 定值。
- FLOW-03/STG-05 的〈供应计划与动作方案〉：涉质量风险的补货、调拨、清货候选与加严检验范围由 L4 定值。
- FLOW-03/STG-08 的〈供需关闭记录〉：到货质检结果、逐批接收情况与实测 COPQ 由 L1、L4 定值。
- FLOW-07/STG-04 的〈事件范围与根因诊断〉：受影响批次范围、缺陷柏拉图与根因候选排名由 L3 定值。
- FLOW-07/STG-05 的〈重大事件处置包〉：复检、隔离与召回候选的批次清单及打标范围由 L3、L4 定值。
- FLOW-07/STG-08 的〈重大事件关闭与全动作对账记录〉：逐批次处置结果与缺陷是否复发由 L3、L4 定值。

## 4 重标定触发条件

- **口径变**：AGT-045 发布〈缺陷分类与不合格判定口径〉，或改不合格率的分子分母、批次与物料对象、接收准则；AGT-046 的质量状态、来源与新鲜度口径改版；接收准则由抽检改为全检或反之。
- **数据源变**：来料检验台账字段改版（新增抽样数、缺陷数或处理结果）；平台后台报表或库存台账改版；Case/Event Ledger 首次上线或换版；承运账单与采购台账的科目口径改版。
- **结构变**：新增供应商、物料、品类、仓库或产线，使子组结构与分母变化；引入新的缺陷族；供方发生换料、换产线或转包。
- **主体变**：开放事实 O1（Amazon 65% / 独立站 15% 之外的其余 20% 渠道构成未定名）一旦定名，或新增渠道主体接入命名源 ⇒ L4 的采购额分母与评级适用范围重算。
- **周期到期**：每 2 个完整年度（决策 Q11）重算中心线、控制限分位、Cpk 受控线与评级分界；每年首月按最新承运账单与工时费率重算 L4 的成本单价项。
- **告警触发**：同一「供应商 × 物料」连续 **2** 个自然月命中 C 档，或连续 **3** 批命中特殊原因时，先回 FLOW-03/STG-04 复核抽样与判定口径；复核后仍命中才进入本节的结构变判定。

## 6 冻结与不许自动放行的情形

- 只有「合格 / 不合格」二值记录而给出控制限、`Cpk` 或特殊原因结论 ⇒ 该结论不得进入 FLOW-02/STG-07、FLOW-03/STG-07 或 FLOW-07/STG-07 的受控动作，只能形成 NoActionRecord。
- 建图门槛不满足（子组 < 20 组或单批抽样数 < 50 件）而判特殊原因 ⇒ 该判定冻结在 FLOW-03/STG-04，不得据其拒收、停货或打可疑标。
- 规格上下限未给出而填了 `Cpk` 值 ⇒ 该值不得进入〈新品验证证据包〉的验收判据，也不得写入对外报告。
- 根因候选置信度 < 0.70 而拟打可疑标、冻结批次或发起供应商评审 ⇒ 冻结该动作，只出复检工单。
- 根因候选的同一时点变更项 ≥ 2 项（混杂未排除）而拟作单一根因结论 ⇒ 该结论不得进入〈重大事件处置包〉的处置项，只作候选。
- 缺陷口径未由 AGT-045 签发而把缺陷占比用于跨供应商比较、索赔或对外表述 ⇒ 该比较与表述不得放行。
- 涉召回、销毁、退款或对外声明的处置缺 AGT-043 的法律意见或 AGT-044 的合规判定 ⇒ 停在 Action Intent ＋ 人工工单，不得进入 FLOW-07/STG-07。
- 检验结论滞后于货物发运（在途批次判定未回）而拟放行或拒收 ⇒ 该批次结论冻结在 FLOW-03/STG-04，不得关闭 FLOW-03/STG-08。
- 引用 §1 清单中任一条卡面案例数字（含 AQL 2.5%、抽样 80–200 件、×3.5、1.2% → 4.8%、72%、98.5%、75%、42%、0.8‰ → 3.2‰、3mm → 2mm、置信度 70%、3% → 7% 等）作为本业务取值 ⇒ 该方案不得放行。
- 数据更新后原方案失效（新快照使原控制限、评级或根因候选不再成立）⇒ 回 STG-04 重算，不得沿用旧取值；**已成功动作不得随整单重跑**。
- 本段落在规则格（FLOW-02、FLOW-03、FLOW-07 三跳各自的 STG-01 / STG-02 / STG-03 / STG-06 / STG-07）上的只是上列判据与门禁条件，不引入判别式或预测式。
